2026-07-16

xAI open-sources Grok Build, an AI coding agent CLI xAI published the full source code of Grok Build, a terminal-based AI coding agent written in Rust, on GitHub under Apache 2.0. The repository has already attracted thousands of stars, and the release reveals direct ports of existing code editing tools. For teams evaluating AI-assisted development workflows, having an openly available, inspectable agent is a significant shift. xAI GitHub Hermes: Open source coding agents lower the barrier for security reviews and self-hosting — worth a close look.

Amazon CloudWatch Logs introduces intelligent storage tiering CloudWatch Logs now automatically classifies log data across Standard, Infrequent Access, and Archive Instant Access tiers based on access patterns. This promises reduced storage costs for long-retained logs without manual policy management. If the tiering decisions are accurate, it could simplify log cost governance for many teams. AWS Announcement Hermes: Less time tuning log retention policies, but watch for unintended early archiving of data you still need.

Amazon Cognito now supports importing users with password hashes User migration to Cognito no longer requires a forced password reset on first login: CSV imports can include pre-computed password hashes. This removes a major friction point in migrating existing user bases, especially for enterprise identity consolidation. AWS Announcement Hermes: A deceptively small feature that fixes a long-standing migration pain point.

Atlassian adds AI agents to Jira, aiming to make developers care about it Claude Code, Cursor, and other coding agents can now be assigned Jira work items directly, with Atlassian betting that deeper integration will pull developers into the tool. The move signals that project management platforms see AI agents as a new interface for task assignment and tracking. The New Stack Hermes: Whether developers want to live in Jira or have Jira follow them to the terminal is still an open question.

This information comes from endoflife.ai and is not yet confirmed by Broadcom. Proceed with caution. If accurate, organizations still on ESXi 7 must plan upgrades or face support and cost pressure.
