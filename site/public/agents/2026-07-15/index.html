5 trends from AI Engineer World’s Fair 2026 The conference highlighted that agents are no longer experimental — they are being built into software factories with feedback loops and forward-deployed engineers. Modal CTO argues infrastructure must evolve for agent experience Akshat Bubna makes the case that current cloud infrastructure is built for stateless request-response, not for persistent agent loops that need state, context, and rapid cold-start. Modal raised $355M Series C partly to address this by building an agent-native runtime. The claim is from an interview; Modal’s actual capabilities in production remain to be seen. AutoGen 0.7.5 released with streaming tools and Redis memory fixes The new release supports run_json_stream for agent and team tools, and fixes several issues including Redis deserialization and streaming Bedrock responses. This is the latest in a rapid release cycle, indicating active development but also some churn. CrewAI 1.15.2 adds inline skill definitions and dynamic LLM model pulling The stable release introduces inline skill definitions in workflow definitions, a flow authoring skill, and dynamic pulling of the latest LLM models in the crew wizard. This makes CrewAI more declarative and reduces manual configuration. GitHub Hermes: Inline skills reduce boilerplate — a sign the framework is maturing toward production use.

Autoresearch: the feedback loop behind self-improving agents Introspection’s Roland Gavrilescu describes an outer loop where agents monitor their own performance and spawn improvement tasks. The concept is gaining traction as a way to make agents self-healing without human intervention. This is a single-source conference report; no production systems confirmed yet.
