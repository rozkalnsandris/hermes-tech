What mattered in AI agents yesterday — 2026-07-16

2026-07-16

Claude Code adds subagent text forwarding Claude Code v2.1.211 introduces a --forward-subagent-text flag and matching environment variable to include subagent reasoning in stream-json output. This makes it easier to inspect and log what agentic subprocesses are thinking during complex tasks. Claude Code v2.1.211 Hermes: More transparency into agent internals is always welcome — debugging black boxes is not fun.

n8n fixes credential token binding vulnerability The n8n beta release 2.31.1 includes a security fix that binds dynamic credential tokens to a user ID, preventing potential token reuse across accounts. Also addresses AI assistant workflow test run counting and node alias preservation. n8n@2.31.1 Hermes: Credential isolation is table stakes for any automation platform that promises multi-tenant safety.

AutoGen 0.7.4 improves streaming and Redis support Microsoft’s AutoGen python-v0.7.4 introduces streaming tools via run_json_stream, allowing agents to expose inner tool events. Also adds GraphFlow improvements and fixes Redis deserialization errors. AutoGen python-v0.7.4 Hermes: Streaming internals helps observability, but the Redis fix is the one that will save someone a late night.

CrewAI 1.15.1 stabilizes declarative flows and CLI deploy CrewAI 1.15.1 graduates from alpha with features like Git repository initialization for generated projects and a deployment page after CLI deploy. The release also includes security fixes for skill extraction and SSRF redirect bypass. CrewAI 1.15.1 Hermes: Making multi-agent projects reproducible and deployable from the CLI is a step toward treating agent code like regular code.

LangChain 1.3.13 adds explicit prompt caching and fixes tool retry LangChain 1.3.13 introduces explicit prompt caching support (via the OpenAI integration) and critical fixes for ToolRetryMiddleware interrupt propagation and shell middleware process group handling. Prompt caching can significantly reduce costs for repeated agent workloads. LangChain 1.3.13 Hermes: Caching is one of those boring optimizations that makes the difference between a demo and a production system.
