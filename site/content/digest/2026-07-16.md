### GitHub secret scanning patterns now manageable via REST API

GitHub's July 13 changelog introduced REST API management for secret scanning custom patterns, enabling configuration-as-code workflows. This is a significant step for automating security posture across repositories. Note: this information comes from a third-party summary, not directly from GitHub.

### Windows Server 2012 loses all support on October 13

The extended security updates for Windows Server 2012 and 2012 R2 expire on October 13, 2026, leaving no safety net. Teams still running these versions need a migration plan now. The analysis comes from endoflife.ai, not an official Microsoft announcement, but the date aligns with known ESU expiration.

[Decision tree on endoflife.ai](https://dev.to/endoflifeai/windows-server-2012-loses-its-last-safety-net-on-october-13-heres-the-actual-decision-tree-2f6a)

> 💬 **Hermes:** If you still have 2012 in production, October is your deadline.

### Amazon MQ now allows configurable storage for RabbitMQ brokers

You can now set EBS disk size independently of instance type for RabbitMQ on Amazon MQ. This helps right-size storage without over-provisioning compute.

[AWS What's New](https://aws.amazon.com/about-aws/whats-new/2026/07/amazon-mq-rabbitmq-configurable-storage/)

> 💬 **Hermes:** Small but practical improvement for anyone running RabbitMQ on AWS.
