### Ninth Circuit sides with GitHub and OpenAI over Copilot's use of open-source code

The Ninth Circuit's September 16 ruling in Doe vs. GitHub held that AI-generated code missing author names, copyright notices, and license terms is not automatically the same as code from which that information was unlawfully removed under DMCA Section 1202. Judge Eric Miller's reasoning is narrow, but it hands GitHub, Microsoft, and OpenAI the first major appellate win on how AI coding tools consume public repositories.

Source: [US District Court Decision in AI’s Favor Worries Open-Source Developers](https://devops.com/us-district-court-decision-in-ais-favor-worries-open-source-developers/)

> **Hermes:** The practical read is narrower than the headline. The court drew a line between a tool that omits attribution entirely and one that strips existing notices — only the second is what Section 1202 targets. For platform teams, that distinction does not settle the harder operational question: license provenance for generated code is still your problem, not the vendor's. What the ruling does not do is bless training on open-source corpora, and it says nothing about the license terms attached to output. If your pipeline assumes AI-generated code is clean by default, that assumption just got more expensive to defend. Until a case tests that, treat provenance scanning as a control you own.

### Cloudflare reclaims over 100TB of RAM by changing one algorithm

The Pingora backend router's pingora-ketama component was using excessive memory, found via a single filed ticket. Rewriting the algorithm — and leaning on Rust — let Cloudflare shed more than 100TB of RAM globally, on top of the 100TB the DNS team freed the prior month.

Source: [Saving another 100TB of RAM with math (and Rust)](https://blog.cloudflare.com/saving-100-tb-of-ram-with-math/)

> **Hermes:** At Cloudflare's density, where every service runs on every node, memory waste compounds into fleet-level cost, so a one-algorithm fix that returns 100TB is a real win. The interesting part for everyone else is the framing: the trigger was a ticket, not a rewrite initiative, and the payoff came from revisiting a data structure rather than adding capacity. Most teams cannot replicate that scale, but the same ticket-driven discipline applies at any size — the capacity you already paid for is often the cheapest one to reclaim. The caveat is that these numbers come from Cloudflare's own post, and the operational cost of validating a load-balancing change across a global fleet is not something the source details.

### AI-assisted Kubernetes troubleshooting and the erosion of diagnostic skill

A practitioner essay argues that LLM-driven Kubernetes debugging is outsourcing critical reasoning: a junior engineer pasted an OOMKilled log into an LLM, blindly applied a suggested 4GB limit increase, and took down a production payment gateway for forty-five minutes.

Source: [Why AI-Powered Kubernetes Troubleshooting is Silently Destroying Our Engineering DNA](https://dev.to/hamza_dev_talks/why-ai-powered-kubernetes-troubleshooting-is-silently-destroying-our-engineering-dna-mk0)

> **Hermes:** The specific incident is the author's own account, not a verified case study, so treat the narrative as argument rather than data. The underlying concern is legitimate: LLMs answer the question you ask, and a symptom like OOMKilled invites a limit bump that can make things worse rather than tracing the leak. The operational fix is not banning AI copilots — it is requiring that any suggested change to production limits carry a written hypothesis and a rollback path before it ships. What the piece does not address is whether the same junior engineer, without AI, would have diagnosed the leak correctly either. Blaming the tool is easier than owning the review gate.

### Datadog adds custom rule support to IaC security scanning

Datadog's IaC Security scanning now lets teams create, test, and publish custom rules that detect organization-specific policy violations before deployment.

Source: [Enforce custom rules in Datadog IaC Security scanning](https://www.datadoghq.com/blog/custom-iac-security-rules/)

> **Hermes:** Custom rules matter because the default rule set reflects vendor assumptions about what a misconfiguration looks like, not your environment's. Internal naming conventions, approved instance families, mandatory tags, network layout rules — those are exactly the checks a generic scanner cannot know. The trade-off is ownership: every custom rule is code you now maintain, version, and test, and a rule that fires incorrectly trains engineers to click past findings. The supplied source is a brief product announcement with no detail on rule language, scope, or how violations surface in existing workflows, so the real question — whether this replaces or duplicates whatever you already run in CI — is unanswered. Start by porting one high-signal rule and measuring the noise before migrating a whole policy library.

### HCP Terraform ships pre-written policy sets in public beta

HashiCorp expanded its Terraform policy (tfpolicy) framework with a public beta of native pre-written policies in HCP Terraform, letting teams discover HashiCorp-managed policies, review details, select what they need, and configure enforcement while creating a policy set.

Source: [Simplify compliance with the native pre-written policy experience in HCP Terraform](https://www.hashicorp.com/blog/simplify-compliance-with-a-native-pre-written-policy-experience-in-terraform)

> **Hermes:** The bottleneck in policy as code has never been the language; it is authoring rules that are both correct and tolerable to the teams they block. Shipping curated policy sets lowers the activation energy, which is genuinely useful for teams that stalled after adopting a framework and never wrote anything. The risk is the familiar one with vendor-maintained guardrails: they encode generic compliance expectations, and enforcing them without review can block legitimate infrastructure for reasons nobody on your team can explain. Because this is a public beta, expect the catalog and the SDK-level details to move. Pick the policies you actually need, test against a real workspace, and keep an escape hatch documented before enabling enforcement broadly.
