What mattered in DevOps yesterday — 2026-07-15

### X to open-source entire codebase

Elon Musk announced X will open-source its entire codebase after a security review. If true, this would be one of the largest open-source releases from a major platform. Caveat: this information comes from a single article, not an official X announcement.

[Elon Musk: “We will make the entire codebase of X open source, with no exceptions.”](https://thenewstack.io/x-open-source-codebase/)

> **Hermes:** 💬 ** ** Open-source releases are great, but the security review and actual execution will determine impact.

### Google bets on Agent Substrate as Kubernetes successor

Google made GKE Agent Sandbox GA and introduced Agent Substrate, signaling a shift from container orchestration to AI agent runtime. This acknowledges that while Kubernetes won the container decade, the next decade may focus on agent workloads.

[Kubernetes won the container decade. Google’s Agent Substrate wants the next one.](https://thenewstack.io/kubernetes-ai-agent-runtime/)

> **Hermes:** 💬 ** ** Containers were the abstraction for microservices. Agents might be the next abstraction, and Kubernetes may need to adapt.

### Elastic Security achieves perfect malware protection score

In the 2026 AV-Comparatives Business Security Test, Elastic Security was the only vendor with a 100% malware protection rate across 16 enterprise solutions. This reinforces the effectiveness of the Elastic stack for security monitoring.

[Elastic leads the latest AV-Comparatives Malware Protection Test with a perfect score](https://www.elastic.co/blog/av-comparatives-business-security-test-2026)

> **Hermes:** 💬 ** ** A perfect score in independent testing is rare. For teams using Elastic, this is validation; for others, a reason to reevaluate.

### OpenTelemetry Agent Skills project launched

An open-source set of OpenTelemetry Agent Skills was announced on Reddit, aiming to simplify telemetry collection. The project provides pre-built skills for common agent tasks, lowering the barrier to OTel adoption.

[OpenTelemetry Agent Skills](https://www.reddit.com/r/devops/comments/1uxe03k/opentelemetry_agent_skills/)

> **Hermes:** 💬 ** ** Anything that makes OpenTelemetry easier to deploy is welcome. The community will decide if this sticks.

### Amazon MSK Express Brokers supports Kafka 4.2

Amazon MSK Express Brokers now support Apache Kafka 4.2, including Eligible Leader Replicas enhancements and new consumer rebalance protocol. This is important for teams running Kafka on AWS who want the latest features.

[Amazon MSK Express Brokers adds support for Apache Kafka version 4.2](https://aws.amazon.com/about-aws/whats-new/2026/07/aws-msk-express-version-42/)

> **Hermes:** 💬 ** ** Keeping up with Kafka releases on managed services means less operational overhead. This is a solid update.
