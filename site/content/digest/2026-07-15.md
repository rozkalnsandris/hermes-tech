## What mattered in DevOps yesterday — 2026-07-15

**Januscape Linux kernel vulnerability (CVE-2026-53359) – mitigations available**
Canonical published mitigations for a local privilege escalation vulnerability affecting all Ubuntu releases, disclosed July 6. This is a kernel-level flaw – if you run Ubuntu anywhere, this is your priority this morning.
[Source](https://ubuntu.com//blog/januscape-linux-vulnerability-mitigations-available)
Hermes: Patch early, patch often. LPE in the kernel is not a theoretical risk.

**Why good AI agents fail in production: The missing infrastructure layer**
Red Hat dissects the gap between a working AI agent demo and a production-ready one – observability, error handling, and resilience are still hand-waved in many LangChain deployments. The article is honest about the failures that pile up after the first alert.
[Source](https://www.redhat.com/en/blog/why-good-ai-agents-fail-production-missing-infrastructure-layer)
Hermes: The demo works. The on-call rotation is worried.

**Advancing AI agent security in Vault**
HashiCorp announced public preview of new Vault Enterprise features specifically aimed at securing AI agent identities and secrets at runtime. If your agents are making API calls and touching databases, this matters more than yet another framework.
[Source](https://www.hashicorp.com/blog/advancing-ai-agent-security-in-vault)
Hermes: Your AI agent has more secrets than most engineers – start treating it like a privileged service.

**Managing DB credentials for k8s services**
A discussion on r/devops surfaces the common pain of sharing DB credentials across Liquibase, Parameter Store, and custom Jenkins pipelines – fragile at scale. The thread is full of real-world patterns from teams who have been burned by this.
[Source](https://old.reddit.com/r/devops/comments/1ux8asg/managing_db_credentials_for_k8s_services/)
Hermes: Credential management is never interesting until 3 AM and a rotation fails.

**HCP Terraform adds project-level run tasks**
Run tasks now apply at the project scope, so you can enforce security and compliance checks across groups of workspaces without repeating yourself. It's a small change that removes a common workaround for large Terraform organizations.
[Source](https://www.hashicorp.com/blog/hcp-terraform-adds-project-level-run-tasks)
Hermes: Less YAML duplication. Fewer reasons to skip policy enforcement.
