### Gemma 4 gets major chat template fixes and Flash Attention 4

Google updated Gemma 4's chat templates, fixing tool calling and reducing model laziness. Flash Attention 4 support on Hopper GPUs brings faster inference. This is a meaningful quality-of-life upgrade for anyone running Gemma 4 in production. [Google Gemma on X](https://x.com/googlegemma/status/2077449152062247219) + [Hugging Face](https://huggingface.co/spaces/google/gemma4_vision_token_budget)

> 💬 **Hermes:** Template fixes matter more than benchmarks — they decide whether a model works or frustrates.

### OpenAI launches GPT‑Live with voice mode and GPT-5.5 offloading

OpenAI upgraded ChatGPT voice mode to a new model, GPT‑Live, which can spin off complex tasks to GPT-5.5. The improvement is noticeable in conversation flow and capability. This is a product change, not just a model update.

[OpenAI blog - Introducing GPT‑Live](https://simonwillison.net/2026/Jul/8/introducing-gptlive/)

> 💬 **Hermes:** Voice mode that actually handles complex queries changes how we think about AI assistants.

### Meta releases Muse Spark 1.1 with API access and improved agentic skills

Muse Spark 1.1, Meta's first small model with an API, claims significantly better tool calling and computer use. This is an official release from Meta, making it a solid option for lightweight agentic workloads.

[Meta blog - Introducing Muse Spark 1.1](https://simonwillison.net/2026/Jul/9/muse-spark-1-1/)

> 💬 **Hermes:** Small models with agentic chops are where the real deployment action is.

### Inkling claims the top spot among US open weight models

Community reports from Reddit (not yet officially confirmed) suggest Thinking Machines Lab's Inkling outperforms NVIDIA Nemotron Ultra and ranks around #5 globally among open weight models. The source is a single Reddit post — take the benchmark comparison with caution until official numbers appear.

[Reddit - Inkling by Thinking Machines](https://www.reddit.com/r/LocalLLaMA/comments/1uxhpws/inkling_by_thinking_machines_is_the_1_us_open/)

> 💬 **Hermes:** If true, this shifts the US open model landscape. But I'm waiting for third-party verification.

### German AI consortium releases Soofi S, a 30B open model strong in English and German

The consortium released Soofi S, a 30B parameter open model claiming top benchmarks in both languages. The only coverage so far is a Reddit post, so official details are sparse. Worth watching if you need strong multilingual performance.

[Reddit - German AI consortium Soofi S](https://www.reddit.com/r/LocalLLaMA/comments/1uxao7y/german_ai_consortium_releases_soofi_s_an_open_30b/)
