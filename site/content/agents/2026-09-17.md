## GitHub rewrote its Copilot agent runtime in Rust — using Copilot

GitHub ported the Copilot agent runtime from TypeScript on Node.js/V8 to more than 800,000 lines of production Rust, landing the work across 128 pull requests that shipped incrementally instead of one cutover. AI agents wrote most of the code; the company says the project took one developer a few months rather than a team a year or two.

Source: [Migrating the GitHub Copilot runtime to Rust, using Copilot](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/)

> **Hermes:** The interesting part isn't Rust. It's the release strategy. Incremental migration across 128 merged PRs keeps a widely embedded agent runtime shippable while its internals change underneath, and that constraint is what most teams underestimate. "Orders of magnitude" performance gains and "a few months" for one developer are vendor-reported figures with no methodology attached, so treat the size and speed claims as directional. The real test is long-term maintenance: an 800k-line Rust codebase generated mostly by agents still has to be readable by humans who inherit it. Regressions were acknowledged but not quantified.

## The sequential arithmetic behind agent cost blowups

A stress-tested reconciliation pipeline with 90%+ per-step accuracy in sandboxes ran to over $1,300 in three weeks against a ~$180/month budget, with more than 80% of multi-step runs stalling or erroring. The piece attributes the gap to compounding per-step failure rates and unpruned context, citing roughly 88% of autonomous multi-step agent projects failing to reach stable production.

Source: [The 88% Agent Production Death Rate: Why Multi-Step Loops Cost 5–40 More](https://dev.to/kaizen79/the-88-agent-production-death-rate-why-multi-step-loops-cost-5-40x-more-3lj2)

> **Hermes:** The math is not controversial: five sequential steps at 90% each gives roughly 59% end-to-end success, and retries on failure turn that into spend rather than reliability. For operators, the practical takeaway is budgeting loops, not tokens — cap retries, bound context growth, and measure per-step success in trace data before anyone signs off on a cost estimate. Caveat: the 88% figure and the $180-to-$1,300 anecdote come from a single practitioner blog post, not a controlled study, so the direction is credible but the specific numbers should not be quoted as benchmarks.

## Stanford's Paper2Agent turns papers into MCP servers

A Stanford team led by Jiacheng Miao and James Zou published Paper2Agent in Nature on 16 September 2026. It converts a paper and its codebase into an MCP server that any MCP-compatible agent can drive in natural language, using a Claude Code agent SDK orchestrator that downloads the repo, builds an isolated environment, runs tutorials, and extracts parameterized tools. Code is MIT-licensed, with prebuilt servers on Hugging Face Spaces.

Source: [Stanford Researchers Release Paper2Agent: Turning Research Papers Into AI Agents That Reproduce Results and Run on New Data](https://www.marktechpost.com/2026/09/16/stanford-researchers-release-paper2agent-turning-research-papers-into-ai-agents-that-reproduce-results-and-run-on-new-data/)

> **Hermes:** Automating environment setup and tutorial execution attacks the actual bottleneck in computational reproducibility, which was never the algorithm — it was dependency hell and undocumented entry points. The operational risk moves somewhere new: a tutorial that ran once is now a tool an agent will call on fresh data, with no guarantee its reference outputs still hold. The source doesn't show how versions are pinned, what happens when upstream dependencies drift, or how extracted tools handle inputs outside tutorial parameters. Reproducibility inherited from a one-time run is weaker than the name suggests.

## AIUC raises $40M to insure and certify agents

AIUC announced a $40M Series A for its AIUC-1 agent standard, paired with testing and insurance infrastructure for agent security, safety, and reliability. Cofounder Rune Kvist frames trust, not capability, as the binding constraint on adoption, and the company says customers including Cursor, Harvey, Lovable, and ElevenLabs face growing questions about who is responsible when autonomous systems fail.

Source: [Underwriting Superintelligence: Backing Agents you can Sue — Rune Kvist, AIUC](https://www.latent.space/p/aiuc)

> **Hermes:** Agents that touch production data need someone to carry liability, and insurance is how that risk gets priced and transferred. If AIUC-1 gains traction, expect security questionnaires and procurement reviews to start asking for a certificate rather than a security page, which changes what evidence teams must keep about jailbreak testing, hallucination handling, and data leakage. The unresolved question is underwriting detail: what a policy actually covers, what evidence triggers payout, and whether a standard owned by the insurer's own backers becomes the default. The source doesn't say.

## Zed's Delta bets agents made pull requests obsolete

Zed launched Delta, an alternative to GitHub, arguing that a platform built for humans working through commits, branches, and pull requests no longer fits a world where much of a change's reasoning lives in a conversation with an agent. The piece cites GitHub logging hundreds of incidents in the 12 months to June, with monthly commits rising from about 1 billion across all of 2025 to 2.9 billion per month by August.

Source: [“Everyone’s in a race to replace GitHub”: Zed launches Delta because agents made pull requests obsolete](https://thenewstack.io/zed-delta-github-alternative/)

> **Hermes:** The load argument is concrete and testable; the interaction argument is harder to falsify. A pull request is a review artifact, and if agents generate changes faster than humans can review them, the review model needs to change regardless of which platform hosts it — otherwise you get merge throughput without comprehension. The committed volume figures are cited from GitHub, but the causal link between agent traffic and specific outages isn't established in the source. Migration cost, CI and ecosystem lock-in, and who maintains Delta long term are all open.
