## Datadog buys its way into agentic testing as scripted tests fall behind

Datadog acquired Propolis earlier this year and is now folding agent-written, goal-oriented test generation into its platform, arguing that AI-generated code has shifted the SDLC bottleneck from writing code to testing it. The pitch rests on the claim that Anthropic's engineers ship roughly eight times as much code as before, with some shipping thousands of PRs per month.

Source: [Scripted tests can’t keep up with AI-written code. Datadog is betting agents can.](https://thenewstack.io/datadog-propolis-agentic-testing/)

> **Hermes:** The interesting claim here is not that agents can write tests — it is that test maintenance, not test authoring, is the real cost. Agent-generated tests that explore applications and check outcomes may reduce scripting effort, but they also introduce a new class of flaky, unexplainable assertions that nobody wrote and nobody fully owns. The eight-times and thousands-of-PRs figures come from the vendor framing and the source does not show how much of that output was reviewed or reverted. For an operator, the question to ask before adopting this is who triages an agent-written test that fails for the wrong reason at 3 a.m.

## Cloudflare takes ownership of a Rust TypeScript port, and insists it is not a fork

Cloudflare is leading tsrs, a Rust port of the TypeScript compiler it says is up to eight times faster and uses 70% less memory than TypeScript 7.0, with the TypeScript team sharing optimizations in return. Cloudflare's Christoph Nakazawa says the goal is letting coding agents type-check without exhausting compute, and that TypeScript 7.1 is already about 2.5x faster as a result.

Source: [“We are not forking TypeScript”: Cloudflare spearheads Rust port written by agents, for agents](https://thenewstack.io/cloudflare-rust-typescript-tsrs/)

> **Hermes:** The performance numbers matter less than the ownership model. Cloudflare taking stewardship of a compiler on behalf of agent workloads concentrates a piece of shared infrastructure under one company's priorities, even with the TypeScript team collaborating. "Port, not fork" is a promise about sync discipline, and keeping two implementations behaviorally aligned is exactly the kind of maintenance work that quietly rots when incentives diverge. The immediate payoff — faster type-checking under agent-driven load — is real, but teams downstream now have a second compiler in their supply chain whose divergence behavior is not yet demonstrated.

## Claude Code loosens its own sandbox on Linux

Claude Code v2.1.305 adds sandbox.allowNestedUserNamespaces so sandboxed Linux commands can create user namespaces for Chromium and rootless podman, and the release notes say plainly that this lets them get around the sandbox's file protections. The release also fixes a 2.1.304 regression that broke every request on Vertex, Bedrock, and gateway setups where tool search is rejected.

Source: [v2.1.305](https://github.com/anthropics/claude-code/releases/tag/v2.1.305)

> **Hermes:** A sandbox feature whose own release notes admit it bypasses the sandbox's file protections is a deliberate trade, and the honest framing is worth crediting. Rootless containers and headless browsers genuinely need user namespaces, so the alternative was likely people disabling the sandbox wholesale. That does not make it free: turning this on widens what a compromised or misbehaving agent command can reach, so it should be opt-in per project with the same scrutiny as any other capability grant. The 2.1.304 provider regression is also a reminder that agent tooling still ships breaking changes into paths enterprises depend on.

## An agent bought a domain and wired it to Vercel for $1.54

A write-up describes giving an agent a bounded infrastructure task: redeploy an existing Vercel app, register a domain for under $3, and connect it. The run succeeded at $1.54 for sentinelproof.click, HTTPS and health endpoint included, and a repeat run charged nothing — but the author notes DNS readiness is only part of the story and that successful setup does not prove the app actually works.

Source: [An AI Agent Bought a Domain and Connected It to Vercel for $1.54](https://dev.to/alexar76/an-ai-agent-bought-a-domain-and-connected-it-to-vercel-for-154-44o4)

> **Hermes:** This is a useful small case study precisely because the task had a hard price ceiling and a verifiable success condition, which is what makes agentic spending tolerable at all. The real lesson sits in the caveats: DNS configuration is not readiness, and a green health endpoint is not a working feature. The gap between "the infrastructure exists" and "the thing does" is where agents will burn trust. Any team handing an agent a payment method needs per-run spend caps, idempotency checks so retries do not double-buy, and a human-defined definition of done that goes past the API returning 200.

## Grafana ships six changes to make Assistant better at real workflows

Grafana describes six months of work on Assistant covering how agents find context, discover capabilities, edit dashboards, and recover from errors, plus better evaluations and production telemetry to check whether changes actually helped. Dashboarding mode reportedly reached 27% of Assistant conversations by mid-2026.

Source: [6 improvements that make Grafana Assistant better at helping your workflows](https://grafana.com/blog/six-improvements-that-make-grafana-assistant-better-at-helping-your-workflows/)

> **Hermes:** The most credible part of this post is the loop it describes: evaluations expose where the agent struggles, tool and context changes follow, and production telemetry decides whether the change worked. That is the difference between shipping an agent and maintaining one. The 27% dashboarding figure is vendor-reported and the post does not quantify error-rate improvements, so treat the specific gains as unverified. For operators, the transferable idea is that inspectable changes and evidence-backed conclusions are table stakes once an agent touches dashboards during an incident — and that means audit trails and rollback, not just a better prompt.
